# 53. 最大子数组和

> 难度：中等 ｜ 套路：动态规划 / 贪心 ｜ Hot100 序号：53 ｜ LeetCode 53

<details>
<summary>题目</summary>

找出和最大的**连续子数组**（至少含一个元素），返回其和。

| 示例 | 输入 | 输出 |
| --- | --- | --- |
| 1 | `nums = [-2,1,-3,4,-1,2,1,-5,4]` | `6` |
| 2 | `nums = [5,4,-1,7,8]` | `23` |

</details>

## 思维链路速查

```chain
核心思路 | 暴力 → 前缀和 → Kadane | 演进
关键 trick | 以 i 结尾 · 全负成立 | 易错
代码骨架 | 滚动变量 O(1) | 落地
```

暴力枚举区间 O(n³) → 前缀和固定右端 O(n²) → Kadane 把「续上还是重开」合成一次 max。

## 核心思路

```chain
暴力枚举 | 枚举所有 i..j 求和 | O(n³) 慢
前缀和数组 | 固定右端，枚举 i..j 区间 | O(n²)
Kadane | dp[i]=max(nums[i], dp[i-1]+nums[i]) | O(n) 最终
```

| 要素 | 定义 |
|---|---|
| 状态 | `dp[i]` = 以 `nums[i]` 结尾的连续子数组最大和 |
| 转移 | `dp[i] = max(nums[i], dp[i-1] + nums[i])` |
| 初值 | `dp[0] = nums[0]` |
| 答案 | `max(dp[0..n-1])`；可滚动成 `cur` 压到 O(1) |

## 关键 trick

- 「以 i 结尾」把「要不要接上前面」变成一次 max，避开二维枚举。
- 全为负数也对：每步都能拿 `nums[i]` 重开，不被更差的尾巴绑架。
- 要返回**具体子数组**：`cur + nums[i] > nums[i]` 时延伸，否则记新起点。
- 分治 O(n log n)：跨中点最大和 = 左最大后缀 + 右最大前缀。

## 复杂度

| 维度 | 复杂度 |
|---|---|
| 时间 | O(n) |
| 空间 | O(1)，滚动 `cur` |

## 代码骨架

```java
public int maxSubArray(int[] nums) {
    int max = nums[0], cur = nums[0];
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(nums[i], cur + nums[i]); // 续上 or 从 i 重开
        max = Math.max(max, cur);
    }
    return max;
}
```
