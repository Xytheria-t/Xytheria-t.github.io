# 977. 有序数组的平方

> 难度：简单 ｜ 套路：对向双指针 ｜ LeetCode 977

<details>
<summary>题目</summary>

整数数组 `nums` 按**非递减顺序**排序；返回每个数字的平方组成的新数组，同样按非递减顺序。

| 示例 | 输入 | 输出 |
| --- | --- | --- |
| 1 | `nums = [-4,-1,0,3,10]` | `[0,1,9,16,100]` |
| 2 | `nums = [-7,-3,2,3,11]` | `[4,9,9,49,121]` |

</details>

平方把单调数组掰成 V 形：负数段递减、非负数段递增，剩余元素里最大的一定在两端——两端往中间夹，把较大的倒着写进结果尾部。

## 为什么平方后会乱序

| 原序列 | 平方后 | 单调性 |
| --- | --- | --- |
| 全非负 | 递增 | 保持递增 |
| 全为负 | 递减 | 整体反转 |
| 有负有正 | V 形 | 先减后增 |

`x² = |x|²`，所以结果顺序等价于按绝对值升序；绝对值在递增数组上呈 V 形——两端大、中间小。

## 核心思路：两端夹逼，倒序填

```chain
剩余区间 [l, r] | 平方值呈 V 形 | 前提
比较两端平方 | 较大者即当前最大值 | 判定
写入 ans[k--] | 从尾部倒着填 | 单调落地
指针内移 | 取走的一端收缩 | 推进
```

平方值的最大值只可能是 `nums[l]²` 或 `nums[r]²`（越靠中间越接近 0），取走较大者写进 `ans[k--]` 即得升序。

> [!warning] 必须倒序填，不能正序填
> 正序填要「当前最小值」，而最小值在数组中间、位置随区间收缩而移动，无法 O(1) 定位；倒序填要的「当前最大值」恒定在两端。

```chain
枚举全部值 | 平方后整体排序 | O(n log n)
两端夹逼 | 每步产出一个最大值 | O(n)
```

## 归并解法

找第一个 `>= 0` 的分界点，负数段向左读（平方递减）、非负数段向右读（平方递增），二路归并，同样 O(n)；代价是要特判全负 / 全非负，所以**面试默认写两端夹逼版**。

## 复杂度

| 维度 | 复杂度 |
| --- | --- |
| 时间 | O(n)，每个元素被比较一次 |
| 空间 | O(n)，结果数组（不计入则为 O(1)） |

## 代码骨架

```java
public int[] sortedSquares(int[] nums) {
    int n = nums.length, l = 0, r = n - 1, k = n - 1;
    int[] ans = new int[n];
    while (l <= r) {
        int a = nums[l] * nums[l], b = nums[r] * nums[r];
        if (a > b) { ans[k--] = a; l++; }   // 左端平方值更大，取走后右移
        else { ans[k--] = b; r--; }   // 相等时取右端亦可
    }
    return ans;
}
```

## 边界与变体

- 单元素 `[-5]`、全非负 `[1,2,3]`、全为负 `[-5,-3,-2]`：`a > b` 恒不成立或恒成立，等于单向倒填，结果仍升序。
- 含 0 与重复值 `[-2,-2,0,1]`：相等时取右端，结果 `[0,1,4,4]`。
- 溢出：约束 `|nums[i]| <= 10^4`，平方 ≤ 10⁸，`int` 装得下；值域放宽到 46341 起才需 `long`。

<details>
<summary>常见误区 (3条)</summary>

- 误区：先平方再 `Arrays.sort()`。能过但 O(n log n)，没利用「已排序」的前提。
- 误区：正序填 `ans[k++]`。最小值在中间，两端比较给不出最小值。
- 误区：比 `nums[l] < nums[r]` 而不比平方。`-5 < 3` 但平方 `25 > 9`，必须比平方值。

</details>

<details>
<summary>面试问答 (2题)</summary>

Q：为什么剩下的元素里最大平方值一定在两端？

A：`|x|` 沿递增数组先减后增（V 形），内部元素的绝对值都不超过两端之一。

Q：和 [[11. 盛最多水的容器]] 的双指针有什么共通点？

A：都是「对向双指针 + 单调性排除」：每步只比两端就排除掉一整批候选，把 O(n²) 压成 O(n)。

</details>
