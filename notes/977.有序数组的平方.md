# 977. 有序数组的平方

> 难度：简单 ｜ 套路：对向双指针 ｜ LeetCode 977

<details>
<summary>题目</summary>

给你一个按**非递减顺序**排序的整数数组 `nums`，返回每个数字的平方组成的新数组，要求也按**非递减顺序**排序。

| 示例 | 输入 | 输出 | 说明 |
| --- | --- | --- | --- |
| 1 | `nums = [-4,-1,0,3,10]` | `[0,1,9,16,100]` | 直接平方得 `[16,1,0,9,100]`，排序后才是答案 |
| 2 | `nums = [-7,-3,2,3,11]` | `[4,9,9,49,121]` | 负数段平方后反而是大的那头 |

</details>

## 思维链路速查

```chain
平方后乱序 | 负数段平方反而递减 | 困境
两端取最大 | 绝对值最大必在两端 | 核心
倒序填结果 | 从尾往头写 ans | 落地
面试问答 | 与归并解法的对比 | 复盘
```

平方这一步把单调数组掰成 V 形——负数段平方后递减、非负数段平方后递增。既然剩余元素里最大的一定产生在两端，就从两端往中间夹，把较大的那个倒着写进结果尾部。

## 为什么平方后会乱序

| 原序列 | 平方后 | 单调性 |
| --- | --- | --- |
| 全非负 | 递增 | 保持递增 |
| 全为负 | 递减 | 整体反转 |
| 有负有正 | V 形 | 先减后增 |

`-4 < 1 < 3` 平方后变成 `16 > 1 < 9`——负数越靠左（越小）平方后反而越大，所以平方值不再随下标单调。

> [!note] 平方值是「按绝对值」排序的
> `x² = |x|²`，结果序列的顺序等价于按绝对值升序排。而绝对值在递增数组上呈 V 形：两端大、中间小。

## 核心思路：两端夹逼，倒序填

```chain
剩余区间 [l, r] | 平方值呈 V 形 | 前提
比较两端平方 | 较大者即当前最大值 | 判定
写入 ans[k--] | 从尾部倒着填 | 单调落地
指针内移 | 取走的一端收缩 | 推进
```

对当前未处理区间 `[l, r]`，平方值的最大值只可能是 `nums[l]²` 或 `nums[r]²`——因为 `|nums[i]|` 在区间内部只会更小（数组本身递增，越往中间越接近 0）。取走较大者写进 `ans[k]`，`k` 从 `n-1` 递减，得到升序结果。

> [!warning] 必须倒序填，不能正序填
> 正序填需要「当前最小值」，但最小值在数组中间，位置随区间收缩而移动，无法 O(1) 定位；倒序填用的是「当前最大值」，而最大值恒定在两端。方向选反了这题就退化成排序。

```chain
枚举全部值 | 平方后整体排序 | O(n log n)
两端夹逼 | 每步产出一个最大值 | O(n)
```

## 归并视角：等价的另一种写法

先找分界点（第一个 `>= 0` 的下标），负数段从分界点往左读（平方递减）、非负数段从分界点往右读（平方递增），二路归并即可，同样 O(n)。

> [!tip] 两种写法怎么选
> 归并解要先定位分界点，边界（全负 / 全非负）需特判；两端夹逼不关心分界点在哪，代码更短、更不易写错，**面试默认写夹逼版**。

## 复杂度

| 维度 | 复杂度 |
| --- | --- |
| 时间 | O(n)，每个元素被比较一次 |
| 空间 | O(n)，结果数组（不计入则为 O(1)） |

## 代码骨架

```java
public int[] sortedSquares(int[] nums) {
    int n = nums.length, l = 0, r = n - 1, k = n - 1;
    int[] ans = new int[n];
    while (l <= r) {
        int a = nums[l] * nums[l], b = nums[r] * nums[r];
        if (a > b) { ans[k--] = a; l++; }   // 左端绝对值更大，取走后右移
        else { ans[k--] = b; r--; }   // 相等时取右端亦可
    }
    return ans;
}
```

> [!note] 溢出边界
> 本题约束 `|nums[i]| <= 10^4`，平方 ≤ 10⁸，`int` 装得下；若值域放宽到 46341 以上，`nums[l] * nums[l]` 会溢出，需转 `long` 再比较。

## 边界与变体

- 单元素 `[-5]`：循环一次，`ans[0] = 25`。
- 全非负 `[1,2,3]`：`a > b` 恒不成立，等价于从右往左倒填，结果仍升序。
- 全为负 `[-5,-3,-2]`：`a > b` 恒成立，等价于从左到右正读。
- 含 0 与重复值 `[-2,-2,0,1]`：相等时取右端，结果 `[0,1,4,4]` 不变。

<details>
<summary>常见误区 (3条)</summary>

- 误区：先平方再 `Arrays.sort()` 交差。能过但 O(n log n)，且没利用「已排序」这个前提——面试官要的就是这 O(n)。
- 误区：正序填 `ans[k++]`。最小值在中间，两端比较给不出最小值，方向必须倒过来。
- 误区：用 `nums[l] < nums[r]` 比大小而不比平方。负数段会判错（如 `nums[l] = -5`、`nums[r] = 3`，`-5 < 3` 但平方 `25 > 9`），必须比较**平方值**或绝对值。

</details>

<details>
<summary>面试问答 (2题)</summary>

Q：为什么剩下的元素里最大平方值一定在两端？

A：原数组递增，`|x|` 沿下标先减后增（V 形），区间内部的值绝对值都不超过两端之一。所以 `max(nums[l]², nums[r]²)` 就是剩余元素的最大值，可以放心地每步确定一个。

Q：这题和 [[11. 盛最多水的容器]] 的双指针有什么共通点？

A：都是「对向双指针 + 单调性排除」——利用某种单调性质（本题是绝对值的 V 形、容器题是容量上界），每步只比较两端就能确定地排除掉一整批候选，把 O(n²) 枚举压成 O(n)。

</details>
