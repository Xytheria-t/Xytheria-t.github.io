# 11. 盛最多水的容器

> 难度：中等 ｜ 套路：对向双指针（贪心）｜ Hot100

<details>
<summary>题目</summary>

数组 `height` 第 `i` 条线两端为 `(i, 0)`、`(i, height[i])`；取两条线，使其与 x 轴围成的容器装水最多（不可倾斜）。

| 示例 | 输入 | 输出 |
| --- | --- | --- |
| 1 | `height = [1,8,6,2,5,4,8,3,7]` | `49` |
| 2 | `height = [1,1]` | `1` |

</details>

## 思维链路速查

```chain
容量公式 | 矮边高 × 底宽 | 定义
起手最宽 | l=0 / r=n-1 | 起点
移动矮边 | 高边动必不变优 | 核心
指针推进 | 宽度单调减，n-1 步 | 收敛
面试问答 | 贪心正确性证明 | 复盘
```

容量被矮的那条边卡死，底宽从两端起手最大、之后只减不增——每步只需换掉矮边，被丢掉的组合又都能被当前容量压住。

## 容量由什么决定

```chain
高度 | min(h[l], h[r]) | 由矮边决定
底宽 | r - l | 两端最大
容量 | 高度 × 底宽 | 两者相乘
```

> [!note] 木桶效应：水从矮的一侧溢出
> 装水高度不可能超过任意一条边，所以取 `min` 而非 `max` 或平均值——贪心的支点。

## 为什么起手在两端

任意一对 `(i, j)` 的底宽 `j - i ≤ n - 1`，只有 `(0, n-1)` 取到最大。

## 为什么只移动矮边

设 `h[l] < h[r]`，当前容量 `C = h[l] × (r - l)`。

```chain
以 l 为左端 | 任意 k ∈ (l, r] | 待排除
容量上界 | min(h[l],h[k]) ≤ h[l] | 高不过矮边
底宽上界 | k - l < r - l | 窄于当前
结论 | 全部严格小于 C | 安全丢弃
```

对每个 `k ∈ (l, r]`：`min(h[l], h[k]) × (k - l) ≤ h[l] × (k - l) < h[l] × (r - l) = C`——以 `l` 为左端的候选全被 `C` 严格支配，`l` 侧可永久淘汰。移动高边则丢掉「以 `r` 为右端」的候选，它们以 `h[l]` 为上界却压不住（`h[k]` 可能远大于 `h[l]`），漏解风险就在这里。

> [!warning] 等高时移哪边都行
> `h[l] == h[r]` 时两侧候选上界都是 `h[l]`，被丢掉的都 `≤ h[l] × (r-1-l) < C`；代码写 `if (h[l] < h[r]) l++; else r--;`，等高走 `else` 正确。

> [!tip] 只进不退，所以是 O(n)
> 每步宽度减 1，`l` 与 `r` 合计最多移动 `n-1` 次——指针不回退重扫。

## 复杂度

| 维度 | 复杂度 |
| --- | --- |
| 时间 | O(n)，双指针合计移动 n-1 次 |
| 空间 | O(1)，仅两个指针与一个最大值 |

## 代码骨架

```java
public int maxArea(int[] h) {
    int l = 0, r = h.length - 1, ans = 0;
    while (l < r) {
        int cur = Math.min(h[l], h[r]) * (r - l);
        ans = Math.max(ans, cur);
        if (h[l] < h[r]) l++;      // 淘汰矮边（等高时走 else，同样安全）
        else r--;
    }
    return ans;
}
```

## 边界与变体

- 循环用 `l < r`：`l == r` 时宽度为 0，容量必为 0。
- `n = 2`：只算一次容量，一轮结束。
- 全等 `[5,5,5,5]`：每步都走 `else`，答案 `5 × 3 = 15`。
- 严格递增 `[1,2,3,4]`：一路 `l++`，答案是 `4`（取 `(1,3)`），不是宽度最大的 `(0,3)`。

<details>
<summary>常见误区 (2条)</summary>

- 误区：应该移动高边「保留更高的墙」。高度由矮边决定，留着高边只会让上限卡在矮边、宽度还在缩小。
- 误区：把 `min` 写成 `max` 或 `(h[l]+h[r])/2`。水从矮侧溢出，容量取矮边高度。

</details>

<details>
<summary>面试问答 (3题)</summary>

Q：怎么严格证明移动矮边不会漏掉最优解？

A：设 `h[l] < h[r]`，含 `l` 的任意组合满足 `min(h[l],h[k]) × (k-l) ≤ h[l] × (k-l) < C`，全被当前容量压住——最优解必在剩余区间。

Q：这题和 [[42. 接雨水]] 都是水 + 双指针，思路差别在哪？

A：容器求**单个最大值**（排除式：每步取 `max`，淘汰被支配的矮边）；接雨水求**每列水量之和**（累加式：每步结算矮侧一列）。

Q：复杂度还能更低吗？

A：不能。至少要读每个高度一次（否则改一个未读位置就能改变答案），下界 Ω(n)。

</details>
