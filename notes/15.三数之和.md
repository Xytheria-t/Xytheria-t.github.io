# 15. 三数之和

> 难度：中等 ｜ 套路：双指针 ｜ Hot100 序号：3

## 思维链路速查

```chain
核心思路 | 排序 + 固定一端 + 双指针夹逼 | 演进
关键 trick | 去重三连 + 提前剪枝 | 易错
代码骨架 | Java 双指针实现 | 落地
```

暴力三重循环 O(n³) → 排序后固定第一个数，剩余区间用双指针夹逼 O(n²)。

## 核心思路

```chain
暴力 O(n³) | 三重循环枚举所有组合 | 太慢
排序+双指针 | 固定 i，l/r 夹逼，根据和调整指针 | 最终
```

1. 排序（便于去重和指针移动）
2. 外层枚举 i，内层双指针 l=i+1, r=n-1
3. 三数之和 == 0 收集，< 0 左指针右移，> 0 右指针左移
4. 跳过重复元素避免重复三元组

> [!warning] 去重是本题核心考点
> 不去重会输出重复三元组。去重策略：固定位跳同值、双指针跳同值。

## 关键 trick

- **固定位去重**：`i > 0 && nums[i] == nums[i-1]` 时 `continue`，跳过相同起点。
- **双指针去重**：找到三元组后，`while (l < r && nums[l] == nums[l+1]) l++` 跳过相同左值，右侧同理。
- **提前剪枝**：`nums[i] > 0` 时直接 break（最小的数已为正，不可能凑出 0）。
- **边界剪枝**：`nums[i] + nums[n-2] + nums[n-1] < 0` 时 l 右移，`nums[i] + nums[l] + nums[l+1] > 0` 时 r 左移。

## 复杂度

| 维度 | 复杂度 |
|---|---|
| 时间 | O(n²)，排序 O(n) + 双层循环 O(n²) |
| 空间 | O(1)，不算结果数组（排序 O(log n) 栈空间） |

## 代码骨架

```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> ans = new ArrayList<>();
    Arrays.sort(nums);
    int n = nums.length;
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // 固定位去重
        if (nums[i] > 0) break;                            // 剪枝：最小正数不可能凑0
        int l = i + 1, r = n - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum < 0) {
                l++;
            } else if (sum > 0) {
                r--;
            } else {
                ans.add(List.of(nums[i], nums[l], nums[r]));
                while (l < r && nums[l] == nums[l + 1]) l++;  // 左值去重
                while (l < r && nums[r] == nums[r - 1]) r--;  // 右值去重
                l++;
                r--;
            }
        }
    }
    return ans;
}
```

## 边界与变体

- 全零数组 `[0,0,0,0]`：输出 `[[0,0,0]]`，去重后只有一个。
- 无解情况如 `[1,2,3]`：返回空列表。
- 四数之和（LeetCode 18）：外层再套一层循环，复杂度 O(n³)。

<details>
<summary>常见误区 (3条)</summary>

- 误区：不去重直接收集。正确：固定位 + 双指针两侧都要跳同值。
- 误区：`nums[i] > 0` 时 continue。正确：应 break，因为排序后后面的数更大，更不可能凑 0。
- 误区：找到三元组后直接 `l++; r--`。正确：先跳过重复值再移动，否则会漏掉边界去重。

</details>

<details>
<summary>面试问答 (2题)</summary>

Q：为什么排序后可以用双指针？

A：排序后，固定 i，l 右移使和增大，r 左移使和减小——单调性保证每个指针只走一轮，总复杂度 O(n²)。

Q：三数之和和两数之和的关系？

A：两数之和用哈希 O(n)，三数之和是「枚举一个 + 两数之和」，但用双指针替代哈希更省空间且避免去重麻烦。见 [[1. 两数之和]]。

</details>
