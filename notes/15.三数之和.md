# 15. 三数之和

> 难度：中等 ｜ 套路：双指针 ｜ Hot100 序号：3

<details>
<summary>题目</summary>

找出下标两两不同、和为 0 的所有三元组，结果**不可重复**。

| 示例 | 输入 | 输出 |
| --- | --- | --- |
| 1 | `nums = [-1,0,1,2,-1,-4]` | `[[-1,-1,2],[-1,0,1]]` |
| 2 | `nums = [0,0,0]` | `[[0,0,0]]` |

</details>

## 思维链路速查

```chain
核心思路 | 排序 + 固定一端 + 双指针夹逼 | 演进
关键 trick | 去重三连 + 提前剪枝 | 易错
代码骨架 | Java 双指针实现 | 落地
```

三数之和 = 枚举一个数 + 两数之和：排序换来单调性，`l` 右移和增大、`r` 左移和减小；去重则靠排序后的相邻比较。

## 核心思路

```chain
暴力 O(n³) | 三重循环枚举所有组合 | 太慢
排序+双指针 | 固定 i，l/r 夹逼，根据和调整指针 | 最终
```

外层枚举 `i`，内层 `l = i + 1`、`r = n - 1`：和 `< 0` 右移 `l`，`> 0` 左移 `r`，`== 0` 收集。

## 关键 trick

> [!warning] 去重是本题核心考点，两处都要跳
> 固定位 `i > 0 && nums[i] == nums[i-1]` 时 `continue`；命中后先跳过两侧重复值、再各自内移。少一处就出重复三元组。

- **剪枝**：`nums[i] > 0` 直接 break——最小的数已为正，凑不出 0。

## 复杂度

| 维度 | 复杂度 |
|---|---|
| 时间 | O(n²)，排序 O(n log n) + 双层循环 O(n²) |
| 空间 | O(1)，不算结果数组（排序 O(log n) 栈空间） |

## 代码骨架

```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> ans = new ArrayList<>();
    Arrays.sort(nums);
    int n = nums.length;
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // 固定位去重
        if (nums[i] > 0) break;                            // 剪枝：最小正数不可能凑0
        int l = i + 1, r = n - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum < 0) {
                l++;
            } else if (sum > 0) {
                r--;
            } else {
                ans.add(List.of(nums[i], nums[l], nums[r]));
                while (l < r && nums[l] == nums[l + 1]) l++;  // 左值去重
                while (l < r && nums[r] == nums[r - 1]) r--;  // 右值去重
                l++;
                r--;
            }
        }
    }
    return ans;
}
```

## 边界与变体

- 全零 `[0,0,0,0]`：输出 `[[0,0,0]]`，去重后只剩一个。
- 四数之和（LeetCode 18）：外层再套一层循环，O(n³)。

<details>
<summary>常见误区 (2条)</summary>

- 误区：`nums[i] > 0` 时用 continue。应 break——后面的数只会更大。
- 误区：命中后直接 `l++; r--`。要先跳重复值再内移。

</details>

<details>
<summary>面试问答 (2题)</summary>

Q：为什么排序后可以用双指针？

A：固定 `i` 后，`l` 右移和增大、`r` 左移和减小，单调性保证每轮指针只走一次。

Q：三数之和和两数之和的关系？

A：三数之和 = 枚举一个数 + 两数之和；双指针比哈希省空间，也免掉哈希去重。见 [[1. 两数之和]]。

</details>
