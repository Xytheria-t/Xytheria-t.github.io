# 定语从句

英语定语可以无限往后挂，中文定语只能往前堆、且堆不长。所以定语从句是英译汉中改动最剧烈的部分——多数时候它根本不译成定语。

## 思维链路速查

```chain
三种译法 | 前置 · 后置并列 · 状译 | 全景
限定 vs 非限定 | 三步判型 | 判断
which 歧义 | 指「这一点」 | 陷阱
自测问答 | 两道自检 | 复盘
```

译法选前置、后置还是状语化，取决于定语在句中的作用；动手前先按三步判型限定 / 非限定，再防 which 指代整句 —— 判错型，译文的方向就错了。

## 三种译法

| 译法 | 适用 | 例 |
|---|---|---|
| 前置定语 | 从句短（≤ 8 词）且是限定性的 | the cache **that we evicted** → 我们逐出的那个缓存 |
| 后置并列 | 从句长，或主句太短压不住 | the design, **which costs nothing to add**, → 这套设计，几乎不增加成本， |
| 状译法 | 关系词实际表达因果 / 让步 / 条件 | requests **that time out** → 请求**一旦超时** |

> [!tip] 判断顺序
> 先问一句：这个从句换成 `because` / `although` / `if` 还通吗？通，就用状译法；不通，再看长短决定前置还是并列。

## 限定性 vs 非限定性

```chain
看逗号 | 有逗号是非限定 | 第一步
试替换 | 换成状语文通不通 | 第二步
量长度 | 短则前置长则并列 | 第三步
```

非限定性从句（带逗号）只是补充说明，删掉不影响句子成立，中文里通常译成独立短句或括号。限定性从句（无逗号）是在圈定范围，删掉会改变所指，必须紧贴先行词。

> [!note] 剥离之后剩下的才是主干
> 定语从句是长句里最大的一层挂载。按上面三步判完译法，把它整块摘掉，剩下的部分按 [[长难句]] 的流程继续拆——两步是串联的，不是两套方法。它的状译法（because / although / if 还通不通）与 [[词性转换]] 是同一道工序的两面：一个动结构，一个动词性。

> [!danger] which 的歧义
> `which` 有时指前面整句话而不是某个名词。这种情况下只能译成「这」「这一点」，不能往前找先行词硬套。

<details>
<summary>自测问答 (2题)</summary>

Q：什么时候定语从句不能译成前置定语？

A：从句过长，或主句本身太短。中文定语一旦超过八字就压不住，读起来像绕口令，这时必须后置成并列短句。

Q：状译法的判断依据是什么？

A：把关系词换成 because / although / if 之类的连词，如果句意依然成立，说明这个从句在逻辑上表达的是状语关系，就该按状语译。

</details>
