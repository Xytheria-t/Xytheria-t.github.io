# 125. 验证回文串

> 难度：简单 ｜ 套路：双指针 ｜ LeetCode 125

<details>
<summary>题目</summary>

忽略大小写、只保留字母数字字符后，若短语正着读与反着读一样，就是**回文串**。

| 示例 | 输入 | 输出 |
| --- | --- | --- |
| 1 | `s = "A man, a plan, a canal: Panama"` | `true` |
| 2 | `s = "race a car"` | `false` |
| 3 | `s = " "` | `true` |

</details>

清洗后反转比较要多花 O(n) 空间；双指针让左右指针边跳边比，空间压到 O(1)。

## 核心思路

```chain
暴力 O(n) | 过滤 + 反转 + 比较 | 额外字符串
双指针 O(1) | 左右对向跳过非字符，逐位比 | 最终
```

左右指针从首尾对向逼近：各自先跳过非字母数字字符，再统一转小写比较——不等即 `false`。

## 关键 trick

> [!warning] 两个易错点
> 跳过非字母数字即等价于题目说的「移除后再比」，还省掉额外字符串；比较前**两侧都要** `toLowerCase()`，否则 `'A' != 'a'` 会误判。

## 复杂度

| 维度 | 复杂度 |
|---|---|
| 时间 | O(n)，每个字符最多被访问一次 |
| 空间 | O(1)，仅用两个指针变量 |

## 代码骨架

```java
public boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
        while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
        if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r)))
            return false;
        l++;
        r--;
    }
    return true;
}
```

## 边界与变体

- 空串 `""` / 单字符 `"a"`：`l < r` 初始即假，直接返回 `true`。
- 全非字母数字 `"///"`：内层 while 把两侧指针跳到相遇，同样返回 `true`。

<details>
<summary>常见误区 (2条)</summary>

- 误区：整体过滤成新串再反转比较——多花 O(n) 空间，双指针边扫边比即可。
- 误区：只转一侧小写——`'A'` 与 `'a'` 会被判为不同。

</details>

<details>
<summary>面试问答 (2题)</summary>

Q：不调用 `Character` 方法时，怎么判断字母数字和转小写？

A：ASCII 范围判断：`c >= 'A' && c <= 'Z'` 是大写字母、`c >= '0' && c <= '9'` 是数字；转小写用 `c | 0x20`（仅对字母有效）。

Q：和力扣 680 验证回文串 II 的关系？

A：680 允许删至多一个字符：遇到不等时分别试跳左侧 / 右侧，核心仍是双指针。

</details>
