# 125. 验证回文串

> 难度：简单 ｜ 套路：双指针 ｜ LeetCode 125

## 思维链路速查

```chain
核心思路 | 暴力清洗反转 → 双指针对向逼近 | 演进
关键 trick | 跳过非字母数字 · 统一转小写 | 易错
代码骨架 | Java 双指针实现 | 落地
```

暴力思路：清洗字符串再反转比较，O(n) 空间。双指针优化：左右指针对向逼近，边跳边比，O(1) 空间。

## 核心思路

```chain
暴力 O(n) | 过滤 + 反转 + 比较 | 额外字符串
双指针 O(1) | 左右对向跳过非字符，逐位比 | 最终
```

左右指针分别从首尾出发。遇到非字母数字字符就跳过，统一转小写后比较——不等即返回 `false`，相等则继续向中心逼近。

> [!warning] 为什么能跳过非字母数字字符
> 题目定义：「移除所有非字母数字字符之后」正着反着一样。双指针在扫描过程中直接跳过这些字符，效果等价于先清洗再比较，但省掉了额外字符串的空间开销。

## 关键 trick

- **先跳后比**：每个指针先跳过非字母数字字符，再做字符比较——不要跳一个、比另一个。
- **统一转小写**：`Character.toLowerCase()` 在比较前调用，避免 `'A' != 'a'` 的误判。
- **空串 / 全非字符**：左右指针在跳的过程中相遇，循环自然结束返回 `true`——无需特判。

## 复杂度

| 维度 | 复杂度 |
|---|---|
| 时间 | O(n)，每个字符最多被访问一次 |
| 空间 | O(1)，仅用两个指针变量 |

## 代码骨架

```java
public boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
        while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
        if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r)))
            return false;
        l++;
        r--;
    }
    return true;
}
```

## 边界与变体

- 空字符串 `""`：`left < right` 初始即假，直接返回 `true`。
- 全非字母数字 `"///"`：内层 while 把两侧指针都跳到相遇，返回 `true`。
- 单字符 `"a"`：`left < right` 初始即假，返回 `true`。

<details>
<summary>常见误区 (2条)</summary>

- 误区：先整体过滤字符串再反转比较。正确做法是边扫描边比较——双指针跳过非字符即可，无需额外字符串，空间从 O(n) 降到 O(1)。
- 误区：只转一侧小写。比较前**两侧都要** `toLowerCase()`，否则 `'A'` 和 `'a'` 会被误判为不同。

</details>

<details>
<summary>面试问答 (2题)</summary>

Q：如果要求不调用 `Character` 方法，怎么判断字母数字和转小写？

A：ASCII 范围判断——`c >= 'A' && c <= 'Z'` 为大写字母，`c >= '0' && c <= '9'` 为数字；转小写用 `c | 0x20`（仅对字母有效）。本质是把库函数展开成位运算。

Q：本题和力扣 680 验证回文串 II 有什么关系？

A：680 允许**删除至多一个字符**——在本题双指针基础上，遇到不等时尝试跳过左侧或右侧各试一次，递归/迭代判断剩余子串是否回文。核心仍是双指针 + 贪心。

</details>
