# 增译与省译

## 思维链路速查

```chain
形合 vs 意合 | 省译语法符号保信息 | 前提
四类必增 | 主语 · 范畴 · 逻辑 · 复数 | 核心
长难句落地 | 增删后重排语序 | 实战
```

英语靠形态和连词把关系说死（形合），中文靠语义和语序让人意会（意合）。两种语言对不上号的地方，就要增或删，落地见 [[长难句]]、[[词性转换]]。

## 形合与意合

| 英语必须写明的 | 中文可以省 | 处理 |
|---|---|---|
| 名词表动作（静态） | 还原成动词 | 见 [[词性转换]] |
| 代词 it / they | 承前省略 | 省译 |
| 连词 that / which | 靠语序 | 省译 |
| 冠词 a / the | 无对应 | 省译 |
| 复数 -s | 靠「们 / 各种」 | 视语境增译 |
| 时态 -ed / -ing | 靠「了 / 曾 / 正在」 | 视语境增译 |

> [!note] 省译的边界
> 省掉的是**语法符号**，不是**信息**。判断标准：删掉之后中文读者还能不能推出同样的意思？能就删，不能就留。

## 四类必增

```chain
补主语 | 英语被动句无主语 | 最常漏
补范畴 | 加「情况 / 过程 / 问题」 | 抽象名词后
补逻辑 | 加「因此 / 但是」 | 意合处
补复数 | 加「各种 / 们」 | 语境需要
```

> [!warning] 被动句
> 英语被动句在中文里几乎都要补主语或转成主动。`The entry was evicted` 译成「该条目被逐出了」是及格，译成「缓存把这个条目逐出去了」或「这个条目已失效移除」才像中文——要么补出动作执行者，要么干脆去掉「被」字。

<details>
<summary>自测问答 (2题)</summary>

Q：英语的 `it` 什么时候该省、什么时候该留？

A：形式主语的 it 一律省（`it is hard to` → 「很难」）；真正指代前文的 it，如果中文里删掉会让人不知道在说谁，就还原成那个名词。

Q：为什么抽象名词后面常常要加范畴词？

A：英语抽象名词可以直接作中心词，中文则需要「……的情况 / 过程 / 问题」这类范畴词来落地，否则句子悬在半空。

</details>
