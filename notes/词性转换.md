# 词性转换

英语偏好用名词承载动作（静态），中文偏好用动词推进句子（动态）。不转换词性，译文就会带着一股翻译腔。

## 思维链路速查

```chain
静动差异 | 为何要转换 | 前提
四类转换 | 名词 · 介词 · 形容词 · 副词 | 主体
自测问答 | 两道自检 | 复盘
```

先认出两种语言的动静差异 → 掌握四类转换手法 → 自测问答复盘。

## 静动差异

| 英语倾向 | 中文倾向 | 例 |
|---|---|---|
| 名词表动作 | 转成动词 | the **implementation** of → **实现** |
| 介词表方向 | 转成动词 | go **through** the queue → **穿过**队列 |
| 形容词表状态 | 转成动词 | is **unaware** of → **没有察觉** |
| 副词评注 | 转成短句 | **Ironically**, → **讽刺的是**， |

> [!note] 一眼识别翻译腔
> 译文里如果出现「进行……的……」「……的……的……」「对于……的……」，几乎都是没做词性转换，把英语的名词结构原样搬了过来。

## 四类转换

> [!warning] 别过度转换
> 术语名词不要动。`implementation` 在泛泛叙述里可译成「实现」，但在 API 文档里就是「实现类」，转成动词反而丢了术语准确性。同理，英语的冠词、代词、关系词该删就删，见 [[增译与省译]]——转换与增删是同一道工序的两面，又都落地在 [[长难句]] 的拆解重排里。

<details>
<summary>自测问答 (2题)</summary>

Q：为什么英语爱用名词而中文爱用动词？

A：英语每个分句（含从句）只能有一个限定动词，多出来的动作只能降级成名词或分词；中文没有这个限制，动作可以一路用动词排下去，所以节奏天然是动的。主从复合句可以有多个限定动词，但每个分句内部仍只有一个。

Q：什么情况下不该做词性转换？

A：术语性名词。它们是固定指称，转成动词会让读者对不上文档里的 API 名或类型名。

</details>
