# 42. 接雨水

> 难度：困难 ｜ 套路：双指针 / 单调栈 ｜ Hot100

<details>
<summary>题目</summary>

给定 `n` 个非负整数表示每根宽 `1` 的柱子高度，求下雨后能接多少雨水。

| 示例 | 输入 | 输出 |
| --- | --- | --- |
| 1 | `height = [0,1,0,2,1,0,1,3,2,1,2,1]` | `6` |
| 2 | `height = [4,2,0,3,2,5]` | `9` |

</details>

## 思维链路速查

```chain
水位定义 | min(左最高, 右最高) | 核心
按列求 | 前后缀最大值打表 | O(n) 空间
双指针版 | 矮侧先结算，压到 O(1) | 最优
单调栈版 | 按凹槽横向累加 | 另一路
面试问答 | 三种解法取舍 | 复盘
```

水位 = 左右最高柱里**较矮**的那个，减去自身柱高就是该列水量；难点是怎么 O(n) 拿到每列的左右最高——打表、双指针、单调栈三条等价路线。

## 水位由什么决定

```chain
左边界 | 左侧最高柱 lMax[i] | 挡水
右边界 | 右侧最高柱 rMax[i] | 挡水
水位 | min(lMax, rMax) | 取矮的
水量 | 水位 - h[i] | 柱顶以上
```

> [!note] 为什么取 min 而不是 max
> 水从较矮一侧漏走：一侧挡到 5、另一侧只挡到 2，水面最高只到 2。与 [[11. 盛最多水的容器]] 的 `min(h[l], h[r])` 同源。

## 前后缀最大值打表

`lMax[i] = max(h[0..i])`、`rMax[i] = max(h[i..n-1])`（均含当前柱），两趟预处理 + 一趟求和。

```java
public int trap(int[] h) {
    int n = h.length;
    int[] lMax = new int[n], rMax = new int[n];
    lMax[0] = h[0];
    for (int i = 1; i < n; i++) lMax[i] = Math.max(lMax[i - 1], h[i]);
    rMax[n - 1] = h[n - 1];
    for (int i = n - 2; i >= 0; i--) rMax[i] = Math.max(rMax[i + 1], h[i]);
    int ans = 0;
    for (int i = 0; i < n; i++) ans += Math.min(lMax[i], rMax[i]) - h[i];
    return ans;
}
```

## 双指针压到 O(1)

不用打表的依据是一条引理：

```chain
已知 lMax < rMax | 左最高低于右最高 | 条件
右真实最高 ≥ rMax | l 右侧至少含 r..n-1 | 放缩
min 即 lMax | 水位当场确定 | 结算 l
对称 | rMax ≤ lMax 时结算 r | 完备
```

`l` 右侧真实最高 `≥ rMax > lMax`，故 `min(lMax, 右真实最高) = lMax`——`l` 列水位当场确定，可结算并右移；反之结算 `r`。

```java
public int trap(int[] h) {
    int l = 0, r = h.length - 1, lMax = 0, rMax = 0, ans = 0;
    while (l < r) {
        lMax = Math.max(lMax, h[l]);     // 先更新两侧最高，再比较
        rMax = Math.max(rMax, h[r]);
        if (lMax < rMax) ans += lMax - h[l++];   // 左最高更小：l 列水位 = lMax
        else ans += rMax - h[r--];   // 否则 r 列水位 = rMax
    }
    return ans;
}
```

## 单调栈按凹槽累加

栈存下标、高度**单调递减**；扫到更高的柱子 `h[i]` 说明右边界出现，弹出槽底结算一层横向水。

```chain
入栈 | 高度递减，等右边界 | 铺垫
遇更高柱 | 凹槽右边界出现 | 触发
弹槽底 | 新栈顶为左边界 | 定宽高
累加 | (min(左,右) - 槽底) × 宽 | 结算
```

```java
public int trap(int[] h) {
    Deque<Integer> st = new ArrayDeque<>();      // 存下标，高度单调递减
    int ans = 0;
    for (int i = 0; i < h.length; i++) {
        while (!st.isEmpty() && h[i] > h[st.peek()]) {
            int bot = st.pop();                  // 槽底
            if (st.isEmpty()) break;             // 无左边界，接不住水
            int left = st.peek();                // 左边界
            ans += (Math.min(h[left], h[i]) - h[bot]) * (i - left - 1);
        }
        st.push(i);
    }
    return ans;
}
```

> [!tip] 按列 vs 按凹槽
> 双指针**竖着切**（一次算完一列）；单调栈**横着切**（一次算一块矩形水层）。总量相同、切法不同——后者也是 [[Hot100-单调栈]] 套路「遇破坏单调者弹出结算」的典型形态。

## 复杂度

| 解法 | 时间 | 空间 | 视角 |
| --- | --- | --- | --- |
| 前后缀打表 | O(n) | O(n) | 按列 |
| 双指针 | O(n) | O(1) | 按列 |
| 单调栈 | O(n) | O(n) | 按凹槽 |

## 边界与变体

- 水量恒非负：`lMax`/`rMax` 含自身时 `min ≥ h[i]`，两端柱自然算 0（不含自身要 `Math.max(0, ...)` 兜底）。
- `n < 3`：围不出凹槽，所有解法返回 0。
- 单调递增 `[1,2,3,4]` / 全等 `[3,3,3]`：一侧最高就是自己，`min - h[i] = 0`。

<details>
<summary>常见误区 (2条)</summary>

- 误区：双指针里先比较再更新 `lMax`/`rMax`。顺序反了会拿旧最高值判断，必须先 `max` 更新再比较。
- 误区：单调栈存高度而非下标。没下标算不出宽度 `i - left - 1`。

</details>

<details>
<summary>面试问答 (2题)</summary>

Q：接雨水和盛最多水的容器都用双指针，区别是什么？

A：容器求**单个最大值**（排除式：每步取 `max` 淘汰矮边）；接雨水求**总量**（累加式：每步结算矮侧一列）。见 [[11. 盛最多水的容器]]。

Q：三种解法面试写哪个？

A：默认双指针，O(n) / O(1) 还能顺带讲清引理；打表最好懂，适合先立「水位」概念；单调栈要按凹槽取信息时才更值，见 [[Hot100-单调栈]]。

</details>
