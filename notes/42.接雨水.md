# 42. 接雨水

> 难度：困难 ｜ 套路：双指针 / 单调栈 ｜ Hot100

<details>
<summary>题目</summary>

给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

| 示例 | 输入 | 输出 | 说明 |
| --- | --- | --- | --- |
| 1 | `height = [0,1,0,2,1,0,1,3,2,1,2,1]` | `6` | 官方图示的锯齿地形，共积水 6 个单位 |
| 2 | `height = [4,2,0,3,2,5]` | `9` | 本篇「以 `h = [4,2,0,3,2,5]` 逐列验算」用的就是这个样例 |

</details>

## 思维链路速查

```chain
水位定义 | min(左最高, 右最高) | 核心
按列求 | 前后缀最大值打表 | O(n) 空间
双指针版 | 矮侧先结算，压到 O(1) | 最优
单调栈版 | 按凹槽横向累加 | 另一路
面试问答 | 三种解法取舍 | 复盘
```

每列能存多少水只取决于它左右最高柱子里**较矮**的那个——水位减去自身柱高就是该列水量。难点不在公式，而在怎么 O(n) 拿到每列的左右最高：打表、双指针、单调栈是三条等价路线。

## 水位由什么决定

```chain
左边界 | 左侧最高柱 lMax[i] | 挡水
右边界 | 右侧最高柱 rMax[i] | 挡水
水位 | min(lMax, rMax) | 取矮的
水量 | 水位 - h[i] | 柱顶以上
```

> [!note] 为什么取 min 而不是 max
> 水会从较矮的一侧漏走：一侧挡到 5、另一侧只挡到 2，水面最高只能到 2。这是木桶效应，与 [[11. 盛最多水的容器]] 的 `min(h[l], h[r])` 同源。

> [!warning] 柱子自身占位，水量可能为 0
> `lMax[i]`、`rMax[i]` 按「含自身」定义时，`min ≥ h[i]` 恒成立，`水位 - h[i] ≥ 0`——两端柱子自然算 0，无需特判。若按「不含自身」定义，则必须 `Math.max(0, ...)` 兜底。

以 `h = [4,2,0,3,2,5]` 逐列验算（`lMax`/`rMax` 含自身）：

| i | h[i] | 左最高 | 右最高 | 水位 | 水量 |
| --- | --- | --- | --- | --- | --- |
| 0 | 4 | 4 | 5 | 4 | 0 |
| 1 | 2 | 4 | 5 | 4 | 2 |
| 2 | 0 | 4 | 5 | 4 | 4 |
| 3 | 3 | 4 | 5 | 4 | 1 |
| 4 | 2 | 4 | 5 | 4 | 2 |
| 5 | 5 | 5 | 5 | 5 | 0 |

合计 `0+2+4+1+2+0 = 9`。

## 解法一：前后缀最大值（按列打表）

两趟预处理把每列的左右最高算出来，第三趟求和。

```java
public int trap(int[] h) {
    int n = h.length;
    int[] lMax = new int[n], rMax = new int[n];
    lMax[0] = h[0];
    for (int i = 1; i < n; i++) lMax[i] = Math.max(lMax[i - 1], h[i]);
    rMax[n - 1] = h[n - 1];
    for (int i = n - 2; i >= 0; i--) rMax[i] = Math.max(rMax[i + 1], h[i]);
    int ans = 0;
    for (int i = 0; i < n; i++) ans += Math.min(lMax[i], rMax[i]) - h[i];
    return ans;
}
```

## 解法二：双指针压到 O(1)

不用打表的依据是一条引理：

```chain
已知 lMax < rMax | 左最高低于右最高 | 条件
右真实最高 ≥ rMax | l 右侧至少含 r..n-1 | 放缩
min 即 lMax | 水位当场确定 | 结算 l
对称 | rMax ≤ lMax 时结算 r | 完备
```

即 `l` 的右侧真实最高 `≥ rMax > lMax`，所以 `min(lMax, 右真实最高) = lMax`，`l` 列水位已经确定，可当场结算并右移；反之结算 `r`。

> [!note] lMax / rMax 的含义
> `lMax = max(h[0..l])`（已扫过的左侧最高，含当前柱），`rMax = max(h[r..n-1])`（含当前柱）。因为含自身，`lMax - h[l]` 不会为负，直接累加即可。

```java
public int trap(int[] h) {
    int l = 0, r = h.length - 1, lMax = 0, rMax = 0, ans = 0;
    while (l < r) {
        lMax = Math.max(lMax, h[l]);     // 先更新两侧最高，再比较
        rMax = Math.max(rMax, h[r]);
        if (lMax < rMax) ans += lMax - h[l++];   // 左最高更小：l 列水位 = lMax
        else ans += rMax - h[r--];   // 否则 r 列水位 = rMax
    }
    return ans;
}
```

## 解法三：单调栈（按凹槽横向累加）

栈里存下标、对应高度**单调递减**。扫到更高的柱子 `h[i]` 就说明右边界出现了，弹出槽底结算一层横向水：

```chain
入栈 | 高度递减，等右边界 | 铺垫
遇更高柱 | 凹槽右边界出现 | 触发
弹槽底 | 新栈顶为左边界 | 定宽高
累加 | (min(左,右) - 槽底) × 宽 | 结算
```

```java
public int trap(int[] h) {
    Deque<Integer> st = new ArrayDeque<>();      // 存下标，高度单调递减
    int ans = 0;
    for (int i = 0; i < h.length; i++) {
        while (!st.isEmpty() && h[i] > h[st.peek()]) {
            int bot = st.pop();                  // 槽底
            if (st.isEmpty()) break;             // 无左边界，接不住水
            int left = st.peek();                // 左边界
            ans += (Math.min(h[left], h[i]) - h[bot]) * (i - left - 1);
        }
        st.push(i);
    }
    return ans;
}
```

> [!tip] 按列 vs 按凹槽
> 双指针是**竖着切**：一次算完一列从底到顶的水；单调栈是**横着切**：一次算一块矩形水层（可能横跨多列）。总量相同，切法不同——这也是 [[Hot100-单调栈]] 套路「遇破坏单调者弹出结算」的典型形态。

## 复杂度

| 解法 | 时间 | 空间 | 视角 |
| --- | --- | --- | --- |
| 前后缀打表 | O(n) | O(n) | 按列 |
| 双指针 | O(n) | O(1) | 按列 |
| 单调栈 | O(n) | O(n) | 按凹槽 |

## 边界与变体

- `n < 3`：围不出凹槽，所有解法自然返回 0（双指针 `l < r` 最多算一次且两端为最高）。
- 单调数组 `[1,2,3,4]`：每列的一侧最高就是自己，水位 = 柱高，水量全 0。
- 全等高原 `[3,3,3]`：`min(lMax, rMax) - h[i] = 0`，答案 0。
- 大凹槽 `[5,0,0,0,5]`：中间三列各 5，共 15。
- 力扣 407 接雨水 II：二维版本（非 Hot100），从边界最矮处向内 BFS，同是「水位由最矮边界决定」。

<details>
<summary>常见误区 (3条)</summary>

- 误区：水位取 `max(lMax, rMax)`。较矮一侧会漏水，必须取 `min`。
- 误区：双指针里先比较再更新 `lMax`/`rMax`。顺序反了会拿旧的最高值判断，水位算错；必须先 `max` 更新、再比较结算。
- 误区：单调栈存高度而非下标。没有下标就算不出宽度 `i - left - 1`，栈里必须存下标。

</details>

<details>
<summary>面试问答 (3题)</summary>

Q：为什么 `lMax < rMax` 时就能确定 `l` 列的水位？

A：`l` 的右侧真实最高至少包含区间 `[r, n-1]`，因此 `≥ rMax > lMax`；于是 `min(lMax, 右侧真实最高) = lMax`，水位当场确定。此时 `l` 列信息已经完备，可以累加并永久右移，这正是把空间从 O(n) 压到 O(1) 的关键。

Q：接雨水和盛最多水的容器都用双指针，区别是什么？

A：容器求**单个最大值**，每步取 `max` 并淘汰被支配的矮边（排除式）；接雨水求**总量**，每步结算矮侧一列、累加进答案（累加式），且要边走边维护两侧最高作水位。见 [[11. 盛最多水的容器]]。

Q：三种解法面试写哪个？

A：默认写双指针——O(n) 时间、O(1) 空间，且能顺带讲清引理。前后缀打表最好懂、适合先讲清「水位」概念；单调栈在需要「按凹槽」信息（如求每个凹槽的位置）时才更有价值，见 [[Hot100-单调栈]]。

</details>
