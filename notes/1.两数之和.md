# 1. 两数之和

> 难度：简单 ｜ 套路：哈希 ｜ Hot100 序号：1

<details>
<summary>题目</summary>

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出**和为目标值** `target` 的那两个整数，并返回它们的数组下标。你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。你可以按任意顺序返回答案。

| 示例 | 输入 | 输出 | 说明 |
| --- | --- | --- | --- |
| 1 | `nums = [2,7,11,15]`, `target = 9` | `[0,1]` | `nums[0] + nums[1] = 9` |
| 2 | `nums = [3,2,4]`, `target = 6` | `[1,2]` | 唯一解，下标从 0 起 |
| 3 | `nums = [3,3]`, `target = 6` | `[0,1]` | 两个 3 是不同元素，可同值不同下标 |

</details>

## 思维链路速查

```chain
核心思路 | 暴力 → 一遍哈希 | 演进
关键 trick | 先查后插 · 下标返回 | 易错
代码骨架 | Java 实现 | 落地
```

暴力双重循环枚举 → 一遍哈希表边走边存 → 复杂度从 O(n²) 压到 O(n)。

## 核心思路

```chain
暴力 O(n²) | 双重循环枚举 complement | 慢
哈希表 | 边走边存，查 target-nums[i] | 最终
```

一遍哈希：遍历时先查 `target - nums[i]` 是否已在 map，命中即返回，否则把当前值存入。

## 关键 trick

- 「先查后插」避免自己配自己（而非先建表再查）。
- 返回的是**下标**，不是值。
- 输入保证恰好一个解、且不可重复使用同一元素。

## 复杂度

| 维度 | 复杂度 |
|---|---|
| 时间 | O(n) |
| 空间 | O(n)，哈希表存已遍历元素 |

## 代码骨架

```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> seen = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (seen.containsKey(need))
            return new int[]{ seen.get(need), i };
        seen.put(nums[i], i);          // 先查后插，避免自配
    }
    return new int[]{};
}
```
