# 1. 两数之和

> 难度：简单 ｜ 套路：哈希 ｜ Hot100 序号：1

<details>
<summary>题目</summary>

返回和为 `target` 的两个下标；保证恰有一解，同一元素不可用两次。

| 示例 | 输入 | 输出 |
| --- | --- | --- |
| 1 | `nums = [2,7,11,15]`, `target = 9` | `[0,1]` |
| 2 | `nums = [3,3]`, `target = 6` | `[0,1]` |

</details>

## 思维链路速查

```chain
核心思路 | 暴力 → 一遍哈希 | 演进
关键 trick | 先查后插 · 下标返回 | 易错
代码骨架 | Java 实现 | 落地
```

暴力双重循环枚举 O(n²) → 一遍哈希边走边存：先查 `target - nums[i]`，命中即返回，否则把当前值存下。

## 核心思路

```chain
暴力 O(n²) | 双重循环枚举 complement | 慢
哈希表 | 边走边存，查 target-nums[i] | 最终
```

## 关键 trick

- 「先查后插」避免自己配自己（而非先建表再查）。
- 返回的是**下标**而非值。

## 复杂度

| 维度 | 复杂度 |
|---|---|
| 时间 | O(n) |
| 空间 | O(n)，哈希表存已遍历元素 |

## 代码骨架

```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> seen = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (seen.containsKey(need))
            return new int[]{ seen.get(need), i };
        seen.put(nums[i], i);          // 先查后插，避免自配
    }
    return new int[]{};
}
```
